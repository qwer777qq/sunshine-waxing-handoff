## 로컬 연결 확인

2026-10-31 이 PC의 `goni-reel` MCP `studio_status`: standalone, 서버·브라우저 불필요, FFmpeg·ffprobe 사용 가능. 상태 점검은 실제 콘텐츠 렌더를 뜻하지 않는다. 매 작업마다 다시 확인한다.
