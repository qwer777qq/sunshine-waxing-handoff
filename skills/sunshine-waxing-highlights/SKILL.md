# 선샤인 왁싱 숏츠 하이라이트

## 2026-11-16 최신 승인 디자인 — 과거 색·프레임 규칙보다 우선

사진과 시술 장면을 크게 보여주는 클린 베이지를 기본값으로 사용한다. [현재 디자인 기준](references/current-design.md)과 [photo-first-v1 실행 안내](https://github.com/qwer777qq/sunshine-waxing-handoff/tree/main/templates/photo-first-v1)를 먼저 읽는다. 5가지 영상 기본형, 시작 로고 2초, 전체 화면형 제목 2.8초, 기본 1.2배속, 선택적 빨간 핵심어 자막을 사용한다. 새 디자인 데모와 여성 TTS를 포함한 게시 완성본을 구분한다. 임산부 사진은 현재 플레이스 업체 공개 사진이며 Instagram 다운로드 완료로 보고하지 않는다. 이 섹션과 사용자의 새 지시가 아래 과거 주황·노랑·고정 자막 기준보다 우선한다.

선샤인왁싱의 실제 소재로 시청자가 변화와 관리 과정을 쉽게 이해하는 세로 영상을 만든다. 사용자가 지정한 소재, 길이, 개수, 채널, 현재 요청을 우선한다. 일반 선샤인 콘텐츠 기준은 [sunshine-waxing-content](../sunshine-waxing-content/SKILL.md)의 최신 지시와 영상·TTS 참조를 적용한다. 이 스킬 호출만으로 게시 권한은 생기지 않는다.

## 입력과 선정

1. 실제 파일 또는 접근 가능한 링크를 확보하고 영상·음성·사진을 직접 확인한다. 사진만 있으면 사진 기반 영상으로 구분한다. 원본이 없거나 확인이 막히면 파일 또는 접근 가능한 자료를 요청한다. 제목과 링크만으로 장면이나 타임코드를 만들지 않는다.
2. 시술 부위, 실제 과정, 결과, 촬영 방향과 고객 식별정보를 확인한다. 실제 원본에서 시작·끝과 선정 이유를 기록하고, 단독으로 이해되는 장면을 고른다. 작업물의 작업 전과 완성 후가 한눈에 확실히 보이도록 같은 대상·부위가 확인된 장면을 짝지어 방향과 크기를 가능한 한 맞춘다. 전후를 명확히 구분하고 변화가 크롭·자막에 가려지지 않는지 확인한다. 실제로 짝이 확인되지 않거나 결과가 보이지 않으면 전후를 만들어내지 말고 필요한 소재를 요청한다.
3. 첫 1~2초에 실제 장면과 간결한 고객 질문 또는 변화의 핵심을 제시하고, 확인된 과정과 결과를 이어간다. 장면 길이와 속도는 원본에 맞게 조절한다. 결과를 만들거나 과장하지 않는다. 참고 채널의 접근·분석 상태와 적용 방식은 [레퍼런스와 실행 범위](references/benchmark-and-engine.md)를 확인한다.

## 검수와 납품

새 작업 폴더를 사용해 기존 원본·편집본을 보존한다. 출력 파일의 전체 디코딩, 해상도·길이·오디오를 확인하고 처음·중간·끝과 컷 경계의 실제 화면, 자막, 음성 싱크 및 소리를 검수한다. 편집 설정·자막 파일·선정 근거와 MP4를 함께 보관한다. 작업 상태를 구분해 보고한다. 원본 없이 스킬을 준비한 것은 영상 완성이나 실전 테스트 완료가 아니다.

제작만 요청했다면 외부 게시를 하지 않는다. 게시를 요청받은 경우 대상 채널과 계정을 확인하고, 중복 여부와 게시 결과를 실제 화면에서 검증한다.
