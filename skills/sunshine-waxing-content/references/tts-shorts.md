## 음성·싱크

2026-10-31 사용자 지시: 앞으로 선샤인 숏츠의 기존 허락받은 여성 TTS는 이전 영상보다 조금 더 밝고 경쾌하게 표현한다. 과장된 광고 톤이나 부자연스러운 고음은 피하고, 짧은 샘플을 실제로 들어 자연스러운 억양과 명료도를 확인해 조정한다. 1.2배속 선호는 `sunshine-waxing-highlights`의 현재 기준을 따른다. 속도만 높였다고 밝은 톤이 구현됐다고 간주하지 않는다.

1. 짧은 질문 → 실제 관리 방식 → 고객이 확인할 조건 → 매장 검색/예약 안내로 대본을 만든다. 길이는 문장과 실측 음성에 맞춘다.
2. 한 문장당 한 클립. `pipeline.narration.narration_smooth`로 생성한다. `config.json`의 `natural` 프리셋을 사용하고 새 대본에 legacy intro 프리셋을 넣지 않는다.
3. 첫 생성 뒤 `clips.json`의 실측 길이로 장면 길이를 다시 맞춘다. 문장 사이 약 0.30초를 둔다. 현재 narration_smooth 캐시에는 voice_id 비교가 없으므로 **화자 변경 시 새 대본 basename/작업 폴더를 사용**하고 남성 음성 캐시를 재사용하지 않는다. 영상 길이에 억지로 맞춰 발음을 자르지 않는다.
4. `pipeline.audio.voice_natural`로 마감하고 `_N.mp3`를 영상에 합성한다. afftdn·과도한 컴프·유명인 모사 피치 변조는 쓰지 않는다. 수치는 실측값을 기록한다.
5. STT 왕복 검수로 매장명·캐론랩·화곡역·출구·핵심 문장 누락 여부를 확인한다. STT를 청취 검수라고 부르지 않는다. 가능한 재생/청취와 음량·피크 측정을 함께 수행한다.

## 화면과 키워드

- 1080×1920, 30fps. 첫 1~2초부터 질문이 크게 보이게 한다. 한 화면에 한 생각, 큰 한글 1~2줄, 실제 사진의 완만한 움직임, 브랜드 아이보리·브라운·주황을 유지한다. 플랫폼 하단 UI와 주요 문구가 겹치지 않게 한다.
- 지역·실제 시술·고민과 연결된 키워드를 제목·본문·해시태그에 실제 반영한다. ‘저통증 왁싱·소량 왁싱·캐론랩·화곡 왁싱’은 실제 관리 방식 문맥으로 쓴다.
- ‘무통증’은 검색 의도나 질문으로 언급할 수 있지만 통증 제로를 보장하지 않는다. 예: ‘무통증 왁싱, 정말 가능할까요?’ 다음에 통증·피부 반응의 개인차와 상담을 설명한다. 전후 사진을 통증 감소의 증거라고 설명하지 않는다. `#무통증보장` 같은 태그는 쓰지 않는다.
- 게시용 후킹과 본문은 네이버·구글 및 사용 가능한 API 결과를 확인해 선정한다. 후보 키워드와 실제 반영·게시를 구분한다.

## 납품·발행
