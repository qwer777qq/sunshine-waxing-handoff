# 2026-11-16 최신 승인 디자인

클린 베이지, 큰 실제 사진 영역, 짧은 제목을 기본으로 한다. 과거 주황/노랑 고정 프레임 기준보다 최신 사용자 승인을 우선한다.

- [현재 제작 기준](https://github.com/qwer777qq/sunshine-waxing-handoff/blob/main/CURRENT_DESIGN.md)
- [영상 기본형 5종과 실행 안내](https://github.com/qwer777qq/sunshine-waxing-handoff/tree/main/templates/photo-first-v1)
- [승인 시안과 편집 원본](https://github.com/qwer777qq/sunshine-waxing-handoff/tree/main/designs/approved-20261116)

실행 도구는 스킬 폴더에 포함된다고 가정하지 말고 저장소를 받아 경로를 확인한다. 전체 화면형, 제목 띠형, 최소 로고형, 임산부 사진형, 전후 사진 강조형이 있다. 시작 로고 2초, 전체 화면형 제목 2.8초, 기본 1.2배속을 사용한다. 원본 전후가 확인되지 않으면 임의로 만들지 않는다.

승인 여성 음성을 합성한 게시 완성본과 무음 디자인 데모를 구분한다. 임산부 사진은 현재 플레이스 업체 공개 사진이며 Instagram 수집 완료로 보고하지 않는다. 고객 원본과 인증정보는 로컬에서 보존한다.
