# 선샤인 사진 중심 릴스·쇼츠

2026-11-16 승인안: 따뜻한 클린 베이지, 실제 시술 사진·영상이 중심, 글자는 짧게. 최신 사용자 지시를 우선하고 과거 주황 고정 프레임으로 되돌리지 않는다.

## 실행 위치

설치 스크립트가 이 스킬의 `assets/toolkit/`에 코드·폰트·승인 시안을 함께 복사한다. 다른 PC의 원래 절대 경로나 클라우드 계정은 필요 없다. 저장소 안에서 사용하는 경우에도 아래 실행기가 저장소의 같은 파일을 찾아 사용한다.

먼저 `scripts/run.py --check`로 Python/Pillow/FFmpeg/ffprobe와 포함 자산을 확인한다. 설치된 스킬의 실제 절대 경로로 실행한다.

```text
python <이 스킬 폴더>/scripts/run.py --check
python <이 스킬 폴더>/scripts/run.py --preset photo-demo --output <새 출력 폴더>
```

상세 설정은 설치 폴더의 `assets/toolkit/templates/photo-first-v1/README.md`를 읽는다. 저장소에서 직접 사용할 때는 루트 `templates/photo-first-v1/README.md`를 읽는다. 모든 출력 경로는 원본과 분리한 새 폴더로 지정한다.

## 기본형 선택

|preset|선택 기준|
|---|---|
|`full`|추천. 실제 시술 전체 화면과 왼쪽 위 두 줄 제목|
|`strip`|제목을 얇은 상단 공간에 분리|
|`minimal`|실제 시술만 크게, 작은 시작 로고|
|`maternity`|임산부 사진의 전체 영역과 원래 문구 보존|
|`before-after`|확인된 같은 고객·부위의 전후 사진을 상하로 크게|
|`photo-demo`|포함된 공개 사진으로 실행 확인용 데모|

영상은 `--input <원본> --start <시작 초> --duration <출력 초>`로 교체한다. 기본 1.2배속이므로 원본 길이는 출력보다 1.2배 필요하다. 가로 영상은 실제 화면을 보고 `--crop x,y,너비,높이`를 정하며 기존 샘플 좌표를 무조건 복사하지 않는다.

전후형은 `--before <사진> --after <사진>`으로 교체한다. 같은 고객·부위와 전후 순서를 확인한다. 별도 JSON의 `pair_evidence`를 새 소재에 맞춰 기록하고 `pair_verified`는 확인 후에만 true로 둔다. 같은 사진을 전후로 중복 사용하거나 피부·털을 바꾸어 결과를 만들지 않는다. 넓은 가로 사진은 중요한 변화가 잘리지 않는 크롭인지 확인하며 필요하면 fit을 contain으로 바꾼다.

## 쇼츠 썸네일 5종

별도 표지 시안을 만들 때는 toolkit의 `templates/shorts-covers-v1/README.md`와 `presets.json`을 사용한다. 기본 추천은 01 사진 전체형, 실제 전후는 05 비교형이다. 사진과 두 줄 이내 제목을 바꾸고 `python <toolkit>/templates/shorts-covers-v1/render.py --config <설정 JSON> --output <새 폴더>`로 1080×1920 PNG·WebP·편집 SVG를 만든다. 저장소 안에서는 toolkit 대신 저장소 루트를 사용한다. SVG를 전달한 상태와 Figma 파일 자체를 수정한 상태를 구분한다.

## 유지할 기본값

- 1080×1920, 30fps. 영상 1.2배속, 로고 첫 2초, full 제목 첫 2.8초.
- 크림 #F5F0E8, 브라운 #51453C. 사진 위 짧은 흰 제목. 빨강은 필요한 자막 핵심어만.
- 큰 장식 프레임·피부 미화·불필요한 엔딩 카드를 추가하지 않는다.
- TTS는 승인된 선샤인 여성 음성 파일을 별도 입력한다. 임의 화자·새 클론·유료 API를 자동 호출하지 않는다. voice가 없으면 무음 디자인 데모이며 게시 완성본으로 보고하지 않는다.
- 임산부 기본 사진은 공개 플레이스 업체 사진이다. Instagram 수집은 미완료다. 주수·효능·안전성·의무 시술을 근거 없이 단정하지 않는다.
- 실제 전후가 없는 시술 과정에는 Before/After를 붙이지 않는다.

## 빠른 제작과 검수

원본의 방향·핵심 부위·사용할 구간을 확인하고 제목과 필요한 자막만 바꾼다. `--cover-only`로 구도를 먼저 확인한 뒤 영상을 렌더한다. 출력의 처음·중간·끝과 전환 시점, 한글 잘림, 사진의 핵심 부위, 소리·길이·비율을 확인한다. 전체 빌드나 무관한 테스트를 반복하지 않는다.

MP4, 표지 PNG, 투명 PNG 레이어, ASS, 설정을 함께 전달한다. 일반 시안과 실제 게시 완료를 구분한다. 이 스킬은 렌더 도구이며 SNS 업로드·GitHub 푸시·계정 설정 변경은 사용자 요청이 있을 때만 수행한다.
