## 3. 템플릿 구현 및 재사용

확인된 기본 출력은 1080×1920, 30fps, H.264 영상과 AAC 음성이다. 사진 두 장을 입력하는 로컬 Python·FFmpeg 템플릿이며 원본 영상 클립을 직접 받는 범용 편집기는 아니다.

- `template.json`: 전후 사진, 로고, 음성 경로, 속도, 전환 시간, 자막 시간·내용.
- `render_template.py`: 로컬 렌더 실행 스크립트.
- `template.ass`: 자막 스타일과 애니메이션.
- `cover.ass`: 두 줄 썸네일 문구와 스타일.
- `fonts/`: Pretendard Bold·ExtraBold 등 해당 버전의 글꼴.

새 작업은 기존 폴더를 복사해 새 폴더에서 진행한다. `python render_template.py`는 해당 폴더의 기존 출력과 ASS를 덮어쓸 수 있다. 실행 전에 경로와 덮어쓰기 대상을 확인한다.

사진의 EXIF 방향, 같은 부위 여부, 크롭을 먼저 확인하고 실제 결과가 가려지지 않게 배치한다. 자막 시간은 새 음성에 맞춰 다시 조정한다. 기본 속도 1.2배를 적용하더라도 전후를 식별할 시간은 확보한다.
