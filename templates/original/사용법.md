# 선샤인 숏츠 템플릿 사용법

이 폴더는 크레딧을 쓰지 않는 로컬 FFmpeg 기반 사진 전후 숏츠 템플릿이다. `선샤인_숏츠_템플릿_미리보기.mp4`는 2026-11-08에 동일 고객·부위로 확인한 겨드랑이 전후 사진과 기존 여성 음성을 사용한 디자인 샘플이다. 실제 사진 기반 영상이며 자동 시술 영상은 아니다.

## 수정

`template.json`에서 전·후 사진, 로고, 음성 파일 경로, 원본 음성 기준의 길이와 장면 전환 초, 자막의 원본 기준 시작·끝 초와 내용을 변경한다. 영상과 음성의 `speed` 기본값은 1.2다. 사진은 EXIF 회전과 전후 관계를 먼저 확인한다. 각 자막 안의 `\\N`은 줄바꿈이고, 빨간색은 ASS 색상 태그로 지정한다. 새 음성을 쓸 때는 실제 대사와 시간을 확인해 자막을 다시 맞춘다. 텍스트에는 `{`, `}` 등의 ASS 제어문을 무분별하게 넣지 않는다.

`python render_template.py`를 실행하면 이 폴더의 미리보기 MP4와 `template.ass`를 덮어쓴다. 새 영상은 이 폴더를 복사해 새 폴더에서 작업한다. 실행에는 Python, FFmpeg 및 ffprobe가 필요하다. 현재 스크립트는 사진 두 장용이며 영상 클립을 직접 받지 않는다. 전후 소재별 크롭과 플랫폼 UI 안전 영역은 실제 화면에서 조정한다.

기본 1080×1920, 30fps, H.264/AAC. Pretendard Bold와 작은 등장 확대·페이드, 빨간 핵심 단어, 주황색 정리 후 라벨, 시작부 로고를 적용한다. 플랫폼별 버튼 영역은 앱·기기에 따라 달라지므로 게시 전 실제 화면으로 확인한다. Instagram·Threads·TikTok·Facebook 업로드 실험은 아직 하지 않았다. 여성 음성의 직접 청취도 별도다.
