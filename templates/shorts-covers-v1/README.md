# 쇼츠 썸네일 시안 5종

사진 중심 클린 베이지. 모든 출력은 1080×1920이며 사진·글자·도형이 분리된 SVG도 함께 제공합니다. 기본 추천은 01, 실제 전후 비교는 05입니다.

| 번호 | 구성 | 사용처 |
| --- | --- | --- |
| 01 | 사진 전체 + 흰색 두 줄 제목 | 시술 영상 기본 표지 |
| 02 | 베이지 상단 + 큰 제목 | 주제가 분명한 설명형 |
| 03 | 작은 라벨 + 전체 사진 | 사진을 최대한 보여줄 때 |
| 04 | 원본 정사각 사진 보존 + 짧은 제목 | 임산부 예약 상담 |
| 05 | 실제 전후 사진 2장 + 작은 라벨 | 같은 고객·같은 부위 비교 |

완성 PNG와 SVG는 [samples/shorts-covers](../../samples/shorts-covers/)에 있습니다. SVG는 Figma로 가져와 사진과 글자를 교체할 수 있는 편집 원본입니다. 기존 Figma 파일 자체를 수정한 결과는 아닙니다. 글꼴은 저장소의 `templates/photo-first-v1/fonts/NotoSansKR.ttf`를 설치합니다.

## 다른 PC에서 다시 만들기

저장소 전체를 다운로드한 뒤 Python과 Pillow를 준비합니다.

```sh
python -m pip install Pillow
python templates/shorts-covers-v1/render.py --output outputs/covers-new
```

`presets.json`의 `photo`, `title`, `label`을 교체합니다. 사진 경로는 JSON 파일 위치 기준이며 절대 경로도 됩니다. 제목은 두 줄 이내로 짧게 씁니다. 개인별 설정은 `.local.json`으로 저장하면 Git에서 제외됩니다. 새 설정을 쓸 때는 `--config`를 추가합니다. 기존 출력 폴더를 덮어쓰지 않습니다.

05는 출처에 표시된 전후 순서를 유지합니다. 새 사진 사용 시 `before`, `after`를 모두 지정하고 같은 고객·부위임을 확인합니다. 피부·털 보정은 하지 않습니다. 04는 기존 업체 공개 사진 속 문구를 잘라내지 않도록 원본 전체를 배치했습니다.

쇼츠 표지용 디자인 파일입니다. 플랫폼 게시 화면의 썸네일 지정 및 피드 크롭 검수는 별도입니다.

## 공통 표지 안전 기준

새로 렌더한 표지의 제목·라벨은 가운데 정사각형 크롭을 고려해 배치합니다. 사진 안에 이미 포함된 문구는 자동으로 이동되지 않습니다. 게시 플랫폼의 표지 미리보기를 각각 확인하세요. 기존 samples 이미지는 이전 배치입니다.
